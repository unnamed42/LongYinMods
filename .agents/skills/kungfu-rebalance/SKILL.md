# 功法数值再平衡

数据与脚本在 `KungFuRebalance/`。**目标不是「公式复现」，而是「落在同类别同等级老功法的区间内」。**

**完成判据**：脚本自检 `越界条数: 0`，且外功的 `GetSkillFightScore` 校准结果落在对标区间。

## 0. 只有 7 列能动

`基础威力 / 威力系数 / 修炼需求 / 修炼效果 / 运功效果 / 使用特效 / 内力消耗`

其余 22 列（描述 / 攻击范围 / 子弹 / 架势 / 隐藏…）**一个都别动** —— 脚本靠「与原版行逐字节比对」保证这点。

## 1. 两个战力口径，别混用

| 类别 | 口径 |
|---|---|
| 外功（拳掌/剑法/刀法/长兵/奇门/射术） | `new KungfuSkillLvData(id).GetSkillFightScore()` |
| 内功 / 轻功 / 绝技 | `HeroSpeAddData.GetValue()`（它们 `GetSkillFightScore()` 恒为 0） |

`KungfuSkillLvData(skillID)` 与角色属性无关，可当「功法自身强度」的客观标尺。

## 2. CSV ↔ 字段

`KungfuSkillData.csv` 是 UTF-8 **带 BOM** + **CRLF**，29 列，列名即游戏字段名。

- **等级 = 稀有度**：`0 白 / 1 绿 / 2 蓝 / 3 紫 / 4 顶级 / 5 绝世`。
- `addDamageRatio` / `skillNeeds` 是 `AttriNumData`，下标固定：
  - `attri[6]` = `[力道, 灵巧, 智力, 意志, 体质, 经脉]`
  - `fightSkill[9]` = `[内功,轻功,绝技,拳掌,剑法,刀法,长兵,奇门,射术]`

## 3. 既有规律（按列 × 等级）

| 列 | L0 | L1 | L2 | L3（紫） | L4（顶级） | L5（绝世） |
|---|---|---|---|---|---|---|
| 威力系数 | – | 每属性 +1 | +1 | +1 | +2 | +2~4 |
| 基础威力（外功） | – | +4 固定 | – | ≈×1.53~1.57 | ≈×1.89 | ≈×2.82 |
| 内力消耗（外功） | – | – | – | ×1.5~3 | ×1.9~5.9 | ×4~15 |
| 使用特效 | – | – | +真伤0.1 | +真伤0.15、+命中 | +内劲、+真伤、+命中 | +真伤、+命中、+连击−、+内劲 |
| 运功效果（外功） | – | – | – | – | 从空新建，总量≈4~5 | 从空新建，总量≈10 |
| 运功效果（内功） | 生命/内力 ×2 | ×2 | ×2 + 体力上限40 | ×3~4 + 体力上限60 + 自愈/护体/负面抗性 | ×4~5 + 体力上限80 | ×4~5 + 体力上限100 |
| 修炼需求 | – | – | +10 | +20 | +20 | +20~40 |
| 修炼效果（内功） | – | +生命4/内力4 | … | +小被动 | +生命10~14/内力6~10/负面抗性0.0075 | +生命16~20/内力12~16/负面抗性0.01 |

容易漏的：

- **4 级以上内功加词条**：L4 平均 +3.9 条、L5 +4.9 条；`体力上限` 人人都有，其次 `负面抗性 / 自愈 / 回内 / 护体真气`。
- **L5 绝技运功效果属性值统一 +2**（12→14），漏了绝技战力明显偏低。
- **无内力系数就不给内劲**。
- **下调只针对 4 处**（外伤、回血、吸内、反伤吸内），是 nerf 不是通则。

## 4. 工作流

```bash
cd KungFuRebalance
python3 rebalance_new_skills.py      # 读两组 csv，产出 KungfuSkillData_v2.csv + rebalance_review.tsv
```

末尾打印**运功效果战力分自检**（每组老功法区间 vs 新功法）：`越界条数: 0` 才算过。

外功 `GetSkillFightScore` 校准**必须连游戏**（分数是原生函数算的）：

1. 起游戏 + MCP server；
2. `execute_csharp` 读 `Z:\...\KungFuRebalance\KungfuSkillData_v2.csv`（游戏侧路径是 Wine 映射的 `Z:\`）；
3. 写回 `GameDataController.kungfuSkillDataBase`（`baseDamage` / `manaCost` /
   `addDamageRatio = StringToAttriRatio(威力系数)` / `equipAddData = StringToSpeAddData(运功效果)` …）；
4. `new KungfuSkillLvData(id).GetSkillFightScore()` 逐条打分，与同类别同等级老功法比区间；
5. 越界的按 `目标区间中位 / 当前分` 反解 `基础威力`，迭代到落回区间；
6. 把结果钉进脚本的 `CALIB_BASE`；
7. **收尾把原版值灌回去**（改的是活进程内存，不落盘）。

## 5. 已知坑

| 坑 | 现象 | 处理 |
|---|---|---|
| `威力系数` 混入 `,` | 游戏只解析到逗号前，**静默丢弃后面所有系数** | 改表后扫一遍逗号；分隔符只能是 `;` |
| 隐藏「太祖」系列 id 1051–1059 | 内存有、导出表没有（另一个 mod 加的） | 忽略 |
| `GetSkillFightScore()` 对非外功返回 0 | 以为内功「没战力」 | 改用 `GetValue()` |
| 空字符串喂解析器 | `StringToAttriRatio("")` 抛 `Il2CppException` | 空字段显式给 `new AttriNumData()` / `new HeroSpeAddData()` |
| 作者的改造有手工噪声 | 同原值可能得到两个结果 | 别追求逐行复现，**对齐区间**即可 |

## 6. 权重表

`HeroSpeAddData.GetValue()` 的实测权重已固化在 `rebalance_new_skills.py` 的 `SPE_W`，离线可自检：

| 权重 | 键 |
|---|---|
| 1.0 / 点 | 全属性、全武学、生活技能、`XX潜力`、`击退`、`装备负重` |
| 0.5 / 0.25 / 0.2 | `生命上限` / `内力上限` / `体力上限` |
| 2.0 | `护甲` / `减伤` / `自愈` |
| 5.0 | `移距` / `回体` |
| 25 / 50 | `削内`｜`护体真气` / `吸内` / `反伤吸内` / `药性` |
| 100 / 点 | 绝大多数特效（`真伤`/`命中`/`眩晕`/`破甲`…）、`负面抗性`；`连击-` 为 **−100** |
| 200 | `无敌` / `反弹` |
| 0 | `抗耐药性`；`回内` 666.7、`回血` 1000（单位不同） |
